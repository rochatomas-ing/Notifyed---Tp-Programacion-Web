#Indicaciones para ejecutar

### Desde la terminal de linux, posicionarse en una carpeta nueva destinada a inicializar el proyecto, crearla en caso de que no exista
### cd "Carpeta del proyecto"

###Clonar repositorio:
### git clone https://github.com/rochatomas-ing/Notifyed---Tp-Programacion-Web.git

###Posicionarse en la rama "tp1":
### git checkout tp1

### Inicializar el server
### go run .

### La pagina se podra visualizar en la url http://localhost:8080
