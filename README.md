# Instrucciones para poder correr los test con make

## Clonar el repo utilizando el comando:
### git clone https://github.com/rochatomas-ing/Notifyed---Tp-Programacion-Web.git

## Posicionarse en la carpeta clonada:
### cd Notifyed---Tp-Programacion-Web/

## Pararse en la rama tp2:
### git checkout tp2

## Copiar las credenciales de ejemplo en un .env:
### cp .env.example .env

## Ejecutar el comando make para llamar al makefile que contiene el flujo:
### make
